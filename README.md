# Topper Dream Hub

Build a premium, responsive, mobile-first educational website called “Topper Dream” for JEE study materials and daily PDF uploads.

The website should look modern, premium, clean, and trustworthy, with a strong academic feel. Use a polished design system with elegant gradients, soft shadows, rounded cards, subtle animations, and excellent spacing. The UI must feel high-end but not cluttered. Make it fast, simple to use, and optimized for students who will mostly access it from mobile phones.

Main brand name: Topper Dream

Footer text must include: “Developed by Ghanshyam Roy”

Core purpose:

This website is a study material hub where admins can upload daily PDFs and students can easily browse, search, open, and download them.

Pages / sections to create:

1. Home

2. Daily PDFs

3. Subjects

4. Announcements

5. About

6. Admin Login

7. Admin Dashboard

8. Contact

Home page requirements:

- Hero section with the title “Topper Dream”

- Subtitle like: “Daily JEE study materials, notes, PYQs, and practice PDFs”

- Primary CTA buttons: “View Today’s PDFs” and “Browse Subjects”

- Premium featured cards for Physics, Chemistry, and Mathematics

- A “Latest Uploads” section

- A small stats section like Total PDFs, New Today, Subjects Covered, Active Students

- A clean and inspiring academic look

Study material section requirements:

- Show PDFs as elegant cards

- Each PDF card must include:

  - title

  - subject

  - chapter

  - date

  - material type like Notes, DPP, PYQ, Worksheet, Revision Sheet

  - view button

  - download button

- Add search and filter options:

  - search by title

  - filter by subject

  - filter by chapter

  - filter by date

  - filter by material type

Daily upload requirements:

- Show PDFs in reverse chronological order

- Create a “Today’s Uploads” area

- Make it easy for admins to add new PDFs daily

Admin system requirements:

- Create a simple admin login page

- Create an admin dashboard

- Admin dashboard should allow:

  - upload PDF file

  - enter title

  - choose subject

  - enter chapter

  - choose material type

  - add description

  - select date

  - publish/unpublish material

- After upload, the PDF should appear automatically in the public PDF list

- Admin area should be protected and separate from public pages

Design style:

- Premium educational branding

- Dark blue, white, and subtle gold or cyan accents

- Strong typography

- Smooth hover effects

- Beautiful cards

- Clean navbar

- Sticky header

- Elegant footer

- Fully responsive for mobile, tablet, and desktop

Content style:

- Keep the language simple and student-friendly

- Use JEE-focused wording

- Use practical labels like Notes, DPP, PYQ, Formula Sheet, Revision, Mock Test

- Avoid clutter and unnecessary sections

About page:

- Explain that Topper Dream is built for JEE aspirants

- Mention it helps students access daily study PDFs in one place

- Show “Developed by Ghanshyam Roy” clearly

Footer:

- Include Topper Dream branding

- Include “Developed by Ghanshyam Roy”

- Add quick links and a simple copyright line

Important:

- Make the website look premium and professional

- Keep it simple enough for daily PDF uploads

- Make it easy to expand later

- Use clean components and well-organized layout

- Ensure the site is fully responsive and polished

If backend/database is needed, create a beginner-friendly structure that can later connect to storage and authentication, but keep the current build simple and functional.
